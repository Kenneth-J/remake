# Remake of {{url}}

Made with [Remake](https://github.com/rubenhassid1/remake). Private until it's yours.

| Where | What |
| --- | --- |
| `site/` | The website. This folder is what Vercel serves. |
| `site/_remake/` | Proof page (original vs remake, drag to compare) and the swap board. |
| `MAKE-IT-YOURS.md` | Everything that still belongs to the original, and what Claude needs from you. |
| `REPORT.md` | The latest score, the live link and what's left. |
| `remake/content.json` | The swap file: fill a slot's `swap`, then `remake apply`. |
| `remake/sources/` | The original's source files, when it publishes source maps. |
| `middleware.js` | The passcode gate. Remove the `REMAKE_PASSCODE` variable on Vercel to open the site. |

Until the swap board says 100%, this is a copy of someone else's work. Keep it private.
